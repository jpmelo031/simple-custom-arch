# Simple Custom Arch

A personal project for building a clean, practical, and reproducible Arch Linux setup. This repository will document the configurations, choices, and scripts used to customize the system over time.

## Goals

- Keep the setup simple and easy to understand.
- Store important configuration files in one place.
- Make future installations easier to reproduce.
- Avoid machine-specific data, credentials, and secrets.

## Planned Areas

- [ ] Base packages and system settings
- [ ] Hyprland configuration and keybindings
- [ ] Status bar, launcher, notifications, and wallpaper
- [ ] Terminal, shell, Git, and editor setup
- [ ] Fonts, icons, and color themes
- [ ] Lock screen, idle behavior, clipboard, and screenshots
- [ ] Installation and bootstrap scripts
- [ ] Backup and restore notes

## Initial Plan

1. Define the repository structure.
2. Add current configurations one area at a time.
3. Document required packages and dependencies.
4. Automate only the steps that are stable and repeatable.
5. Test the setup on a clean Arch Linux installation.

## Status

This project is currently in the planning stage. The repository will stay small while the setup takes shape.
